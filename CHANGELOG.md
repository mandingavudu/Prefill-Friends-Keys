# 1.0.1

- Added CurseForge packaging and automatic releases through GitHub Actions when pushing version tags.

# 1.0.0

- Added a five-row scrolling keystone list beside Premade Groups, ordered by own key, party, guild, Battle.net friends, and character friends, with category-based title colors.
- Added keystone sharing with party, guild, and friends, including LibKeystone compatibility for party and guild members.
- Added dungeon and Mythic+ selection when choosing a key, with a copyable key level for Blizzard's protected title field.
- Added an account-wide default playstyle setting in the AddOns options panel, initially set to Competitive.
- Added automatic positioning to avoid overlapping Raider.IO's visible profile panel.
- Added Portuguese and English documentation.
- Added the MIT license.
